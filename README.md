# Day 11 – Data Sorting and Filtering Using Excel

## Project Overview
This project focuses on sorting and filtering sales data using Microsoft Excel to answer important business questions and identify useful sales insights.

## Dataset
- Dataset: Sample Superstore
- Tool: Microsoft Excel
- Data operations: Sorting, Filtering, and Sales Analysis

## Tasks Performed
- Sorted Sales from largest to smallest.
- Sorted Profit from smallest to largest.
- Applied multiple filters on Category, Region, and Sales.
- Identified sales performance across categories, regions, and customer segments.
- Filtered orders with Sales greater than 1000.

## Key Business Insights
1. Technology recorded the highest category sales: 839,893.279.
2. West region recorded the highest regional sales: 739,813.6085.
3. Machines recorded the lowest sub-category profit: -6,599.98.
4. A total of 471 orders had sales greater than 1000.
5. Consumer segment contributed the highest sales: 1,170,659.787.

## Conclusion
This project demonstrates how Excel sorting and filtering features can help analyze sales data, answer business questions, and identify important business insights.
